Projects are the primary way you organize work in Google Platform. Each project gives your team a shared space for tasks, files, discussions, and milestones. Use the guidance below to create your first project, manage its members and settings, and keep everything structured as your work grows.

## Creating a Project

<Steps>
  <Step title="Open the Projects dashboard">
    From the main navigation, click **Projects** in the left sidebar. Then click the **New Project** button in the top-right corner.
  </Step>
  <Step title="Enter project details">
    Fill in the required fields:

    - **Name** — choose a clear, descriptive name (e.g., *Q3 Marketing Campaign*). Project names must be unique within your organization.
    - **Description** — add a short summary of the project's purpose so team members understand its scope at a glance.
    - **Visibility** — select one of the following:
      - **Private** — only invited members can see the project.
      - **Team** — all members of your team can view the project.
      - **Organization** — everyone in your organization can view the project.
  </Step>
  <Step title="Create the project">
    Click **Create Project**. You are automatically added as the project owner and taken to the new project's home page.
  </Step>
</Steps>

## Adding Members to a Project

<Steps>
  <Step title="Open project settings">
    Navigate to your project and click the **Settings** tab near the top of the page.
  </Step>
  <Step title="Go to the Members section">
    Select **Members** from the settings sidebar. You will see a list of everyone currently in the project.
  </Step>
  <Step title="Invite new members">
    Click **Invite Members**, then type the name or email address of the person you want to add. Select their role:

    - **Viewer** — can read project content but cannot make changes.
    - **Contributor** — can create and edit tasks and comments.
    - **Admin** — can manage settings, members, and billing for the project.

    Click **Send Invite**. The invitee receives an email notification and appears in the member list once they accept.
  </Step>
</Steps>

## Project Settings

### Rename a Project

1. Go to **Settings → General**.
2. Update the **Project Name** field.
3. Click **Save Changes**.

### Archive a Project

Archiving hides a project from active views without deleting any data. To archive a project, go to **Settings → General**, scroll to the **Danger Zone**, and click **Archive Project**. You can restore an archived project at any time from the **Archived Projects** list in the Projects dashboard.

### Delete a Project

<Warning>
  Deleting a project is permanent and cannot be undone. All tasks, files, comments, and history associated with the project are immediately and irreversibly removed. Export any data you need before proceeding.
</Warning>

To delete a project, go to **Settings → General → Danger Zone** and click **Delete Project**. Type the project name to confirm, then click **Delete Permanently**.

## Organizing Work with Labels and Milestones

### Labels

Labels let you categorize tasks across a project with color-coded tags (e.g., *Bug*, *Feature*, *Blocked*).

- To create a label, go to **Settings → Labels** and click **Add Label**. Enter a name and pick a color.
- To apply a label to a task, open the task and select one or more labels from the **Labels** dropdown in the task detail panel.
- Filter the project task list by label using the **Filter** bar at the top of the board or list view.

### Milestones

Milestones mark key delivery points in your project timeline.

- To create a milestone, open the **Milestones** tab in the project and click **New Milestone**. Set a title, due date, and optional description.
- Assign individual tasks to a milestone by opening a task and selecting the milestone from the **Milestone** field.
- Track milestone progress — Google Platform calculates completion percentage automatically as assigned tasks are closed.
