Google Platform is built for teams working together — whether you are in the same room or across time zones. You can leave comments on any item, mention teammates to loop them in, watch a live activity feed, and share files and links without leaving your project workspace.

## Commenting and Mentions

Add a comment to any task, document, or project update by clicking the **comment field** at the bottom of the item's detail panel. Type your message and press **Enter** or click **Post** to submit.

### Mentioning a Teammate

To notify a specific person, type `@` followed by their username or display name anywhere in a comment. A dropdown of matching team members appears — select the correct person to insert the mention. The mentioned user receives an in-app notification and, depending on their settings, an email alert as well.

<Tip>
  Use `@here` to instantly notify every member currently active in the project. This is useful for urgent announcements or when you need a quick response from whoever is online. Use it sparingly to avoid alert fatigue.
</Tip>

You can also mention a project or task directly by typing `#` followed by its name, creating a clickable reference inside the comment.

## Activity Feed

The **Activity Feed** gives you a chronological record of everything that has happened across a project. Find it by clicking the **Activity** tab at the top of any project page.

The feed shows:

- **Task changes** — status updates, assignee changes, due date edits, and label additions.
- **Comments and mentions** — every new comment posted on any item within the project.
- **Member events** — when someone joins or leaves the project.
- **File and link additions** — whenever a resource is attached to a task or project.
- **Milestone updates** — progress changes and completion events.

Filter the feed by event type using the **Filter** dropdown at the top of the Activity tab. You can also filter by a specific team member to review one person's contributions.

## Sharing Resources

Attach files and links to any task or project to keep reference material in context.

### Attaching Files

1. Open the task or project detail panel.
2. Click the **Attach** button (paperclip icon) in the toolbar.
3. Select a file from your device — supported formats include images, PDFs, spreadsheets, and most common document types. The maximum file size per attachment is 100 MB.

The file appears in the **Attachments** section of the item and is visible to all project members with at least Viewer access.

### Adding Links

1. In a comment or description field, paste a URL directly — Google Platform automatically renders a preview card for supported sites.
2. Alternatively, click the **link icon** in the text editor toolbar, enter the URL and an optional display label, and click **Insert**.

### Pinning Resources

Pin important files or links to the top of a project's **Resources** tab so they are easy to find. Open the Resources tab, click **Add Resource**, and paste a URL or upload a file. Pinned resources persist independently of tasks and comments.

## Real-Time Presence

Google Platform shows you who else is active in the same project right now. Look for **presence avatars** in the top-right corner of any project page — each avatar represents a teammate currently viewing or editing something in the project.

When two or more people edit the same task description simultaneously, Google Platform applies changes in real time without conflicts, similar to collaborative document editing. You will see a live cursor indicator labeled with the other person's name if they are typing in the same field as you.

If you want to coordinate in the moment, use a `@mention` in a comment or start a thread directly on the task to keep the conversation attached to the relevant context.
